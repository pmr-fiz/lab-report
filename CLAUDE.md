# CLAUDE.md

Инструкции для агента вынесены в **AGENTS.md** (единый источник правды для
Claude Code, Codex и других агентов). Прочитай `AGENTS.md` перед работой —
там пайплайн, стандарт оформления и правила сборки отчёта.

Кратко: структуру проекта из методички воспроизводить точно (иначе — по файлу
`taskK.py` на задание); без комментариев, докстрингов и лишних модулей; в
отчёте — только относящиеся к заданию фрагменты кода; тестовых файлов не
создавать — проверять запуском в терминале; вывод программы — не больше
страницы; не переписывай стандарт в `report_builder.py`/`code_block.py`; отчёт
собирай только через эти модули; перед «готово» — рендер в PDF и визуальная
проверка.
