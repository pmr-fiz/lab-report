---
description: Выполнить лабораторную работу из присланного файла (.docx/.pdf)
---
Пользователь прислал файл задания лабораторной работы (.docx или .pdf).
Выполни всё по инструкции из AGENTS.md:

1. Определи номер лабы N из текста задания («Лабораторная работа №N»); если
   номера нет — возьми следующий свободный labs/<N> и скажи, какой выбрал.
   Создай labs/<N>/ (с src/ и tests/) и сохрани присланный файл как
   labs/<N>/task.docx (или .pdf).
2. Извлеки текст: `python read_task.py labs/<N>/task.docx` (или .pdf).
3. Реши задания (код в labs/<N>/src/), напиши тесты (labs/<N>/tests/, pytest),
   прогони и чини до зелёного. Захвати реальный вывод программ.
4. Собери отчёт ТОЛЬКО через report_builder.py в labs/<N>/report.docx,
   отрендери в PDF и покажи превью. Имя/группу — плейсхолдеры или из config.json.
5. Дай labs/<N>/EXPLAIN.md с подробным разбором лабы.
