# Lab Report Agent

Агент, который по тексту лабораторной работы пишет код,
покрывает его тестами, прогоняет их и оформляет **готовый отчёт Word**.

Работает поверх **Claude Code** или **Codex**.

## Что внутри

| Файл | Назначение |
|---|---|
| `AGENTS.md` | Инструкции агенту: пайплайн, стандарт, правила (Codex и др.) |
| `CLAUDE.md` | То же для Claude Code (ссылается на `AGENTS.md`) |
| `report_builder.py` | Шаблон отчёта: титульник, разделы, контрольные вопросы |
| `code_block.py` | Подсветка кода настоящим текстом на тёмном фоне + блок вывода |
| `read_task.py` | Извлекает текст задания из `.docx` / `.pdf` |
| `.claude/commands/lab.md` | Слэш-команда `/lab` для Claude Code |
| `sample_report.py` | Эталонный пример — запусти, чтобы увидеть образец |
| `config.example.json` | Шаблон конфига с ФИО/группой/кафедрой |

## Требования

- **Claude Code** или **Codex**.
- **Python 3.10+** и зависимости: `pip install -r requirements.txt`
  (`python-docx`, `pypdf`, `pygments`, `pytest`).
- **LibreOffice** (`soffice`) и **poppler** (`pdftoppm`) — опционально, для
  авто-предпросмотра отчёта. Без них `.docx` всё равно соберётся.

### Быстрый старт

Склонируйте репозиторий:

```bash
git clone https://github.com/<user>/<repo>.git
cd <repo>
```

Создайте виртуальное окружение и установите зависимости:

**Windows (PowerShell):**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python sample_report.py   # соберёт sample_report.docx
```
Если PowerShell блокирует активацию — один раз выполните
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

**macOS / Linux (bash/zsh):**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python sample_report.py   # соберёт sample_report.docx
```

Выход из окружения — команда `deactivate`.

Затем откройте папку проекта в агенте.

### В Claude Code

Claude Code сам подхватит `CLAUDE.md`. Просто **перетащите файл задания
(`.docx`/`.pdf`) в чат** и вызовите слэш-команду:

```
/lab
```

Агент сам определит номер лабы, создаст `labs/<N>/`, положит туда задание, решит
его, прогонит тесты, соберёт отчёт и покажет превью. Без слэш-команды можно
и словами: «вот задание, сделай лабораторную работу по AGENTS.md».

### В Codex

Codex читает `AGENTS.md`. Слэш-команды у него нет — приложи файл задания и
напиши: «Вот задание лабораторной работы, выполни по AGENTS.md: создай папку labs/<N>, реши,
протестируй, собери отчёт и покажи».

## Как пользоваться (на каждую лабу)

1. Пришлите агенту файл задания (`.docx`/`.pdf`) прямо в чат.
2. В Claude Code — `/lab`; в Codex — «сделай лабораторную работу по AGENTS.md».
3. Забери `labs/<N>/report.docx`, при желании посмотри `labs/<N>/EXPLAIN.md`.

Папку `labs/<N>/` создавать вручную не нужно — агент делает это сам, определяя
номер лабы из текста задания.

Данные студента: либо оставьте плейсхолдеры `{{DEPARTMENT}}`, `{{GROUP}}`,
`{{STUDENT_NAME}}` в титульнике и впишите вручную, либо скопируйте
`config.example.json` в `config.json`, заполните — агент подставит значения.

## Настройка 

Стандарт оформления зашит в `report_builder.py` (поля, шрифт, кегль, красная
строка, интервал) и текст титульника — правится в одном месте. Палитра подсветки
кода и цвет фона — вверху `code_block.py` (там же можно сделать светлую тему для
печати).

## Оговорка

Инструмент задуман как помощник: строит каркас, гоняет тесты и оформляет отчёт,
а `EXPLAIN.md` помогает **разобраться** в лабе. Используйте ответственно, а не как
«чёрный ящик для сдачи не глядя».
